# Skills

Agent skills for writing and auditing content against the [spec](../spec/). Each skill maps to one stage:

| Stage | Job |
| --- | --- |
| Brief | Pick the reader's question and its sub-questions, set the anchor claim |
| Draft | Write with one self-contained anchor passage per claim |
| Audit | Check a draft against the spec and flag fixes |

The first skill will be a generalized content-editing skill, adapted so it reads from a term sheet instead of hardcoded product language.
