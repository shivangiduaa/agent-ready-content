# Spec

The rulebook for agent-ready content. The linter, the harness prompt sets, and the writing skills all point back here.

Being ported from the working draft. It will cover:

1. **Best practices**, grouped by where they act: get retrieved, get used, stay identifiable. Each rule carries an evidence label.
2. **Success methodology** across engines: metrics, prompt set design, run protocol, sample sizes, and reporting with intervals.
3. **Content toolkit**: term sheets, claim libraries, and how to stay consistent for agents without sounding robotic to people.
